# 🎧 Spotify Clone

A simple Spotify-inspired music player built using **HTML, CSS, and JavaScript**.  
This project was created for learning purposes to understand how music players work in web development.

It supports:
- Play & Pause
- Next & Previous track
- Song list
- Audio controls

---

## 🚀 Features

- 🎵 Play and pause music  
- ⏭ Next and previous song buttons  
- 📃 Song list display  
- 🔊 Audio player integration  
- 📱 Clean and simple UI  

---

## 🛠 Technologies Used

- HTML  
- CSS  
- JavaScript
